Le Projet

Une application pour gérer un tournoi e‑sport sécurisé

Objectif global

Le projet « Aux Claviers Citoyens » vise à créer une application permettant de gérer un tournoi e‑sport : joueurs, équipes, matchs, scores… L’API doit être fiable, sécurisée et utilisable par différents profils (étudiants, militaires, organisateurs).

Ma mission

J’ai été responsable de toute la partie authentification et gestion des utilisateurs. Mon rôle était de garantir que seuls les utilisateurs autorisés puissent accéder à l’API, et que leurs données soient protégées.

Ce que j'ai mis en place

Développement complet d'un système d'authentification robuste avec architecture sécurisée et tests approfondis.

Architecture technique implémentée
Architecture MVC
  • AuthController.php - Gestion des endpoints d'authentification
  • AuthDao.php - Couche d'accès aux données utilisateurs
  • jwt.php - Helper pour génération/validation des tokens
Base de données sécurisée
  • Table users - Stockage sécurisé des comptes
  • Requêtes préparées - Protection contre injections SQL
  • Index optimisés - Performance des requêtes
Sécurité multi-couches
  • OAuth2 Flow - Authentification standardisée
  • JWT Tokens - Sessions stateless sécurisées
  • Validation stricte - Sanitisation des entrées
Fonctionnalités développées
Système d'authentification complet
Endpoints implémentés :
  • POST /auth/register - Inscription avec validation email
  • POST /auth/login - Connexion OAuth2 Password Grant
  • GET /auth/me - Récupération profil utilisateur
  • POST /token - Rafraîchissement de tokens
Mesures de sécurité :
  • Hachage bcrypt - Mots de passe non réversibles
  • Validation stricte - Email, mot de passe, format des données
  • JWT signés - Tokens non falsifiables
  • Expiration automatique - Sessions limitées à 1 heure
